# Внимание!

После установки этой ОС (zhirach) ваша (Э)ВМ больше не запустится. Также ваш BIOS\UEFI будет стёрт с чипа материской платы. Не забывайте что данная ОС работает как USB-киллер.

Сама ОС может содержать троян (Windows 11 25H2), он установится автоматически. Для вашего удобства мы добавили программу виртуализации других систем - VMware Workstation 17 Pro.

Для профессиональных киберспортсменов в LiveCD есть программа "Steam" и установленная в ней игра "Chess for idiots" чтобы вы могли развлечь себя в любой момент.
